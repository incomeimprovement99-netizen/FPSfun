# 2026-10-06

**STRYDER is a fast pistol now.** STRYDER was a second rifle; it is now a fast automatic pistol, a different gun
from APUHTHEE's six hard shots. If you had STRYDER in a loadout, you still have it.

**Every gun loses damage with range now, the way most shooters work.** Up close the SMGs and pistols are the quickest
killers; at 60 m they take more than twice as long, and the rifle and CHOOCH barely change. HAEFY, which had been
quicker up close than every gun but the shotguns, now kills like the marksman gun it is.

**Hands on the guns.** Other players' soldiers no longer run with the left hand floating off PANDA or ANAKIN. HAEFY,
the last gun, is now held properly too: every gun on the soldier is fitted.
