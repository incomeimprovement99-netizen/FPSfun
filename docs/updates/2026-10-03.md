# 3 October 2026

**The beams read.** MOTEL HILL's beam is really pink now (it drew nearly black), and the jump pads' white beams are a third
as tall, so only the four block beams reach the sky and you can tell at a glance which block you are looking at.

**The insides are lit.** The tower's floors, the big building round its foot, the court and the station are now lit from
their ceiling lamps, so you can see who is in there with you. Outside is as it was.

**Your player card stays up at least 5 seconds** when a battle royale starts, so you can read it.

**The game opens faster again.** The page no longer waits for your soldier to download before you can play: the range
opens first and the soldier arrives behind it. Old character files the game no longer uses are not downloaded at all.

**No more falling back to the old model.** If you open the game while an update is being put on the server, the
soldier's files can fail to come for a moment. The game used to give up straight away and show the old model for
the whole session. Now it tries again a few times over about 13 seconds, so you get the soldier.

**About two more seconds off the first load.** The game builds its graphics while it downloads instead of after, and
the code for playing with friends is only fetched when you start a match with friends.
