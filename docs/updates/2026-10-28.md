# 2026-10-28

**Steadier matches with friends.** If the host leaves while a squad is holding the capture zone, the new host
carries on the meter instead of starting it over. And if your connection to the host drops for a moment, what you do
in those seconds (the guns you drop, a ping, a Gulag result) now reaches the match once you are back, instead of being
lost.

**The server is harder to knock over.** One malformed message to the matchmaking server could crash the whole game
server for everyone until it restarted; it now shrugs those off. One computer can no longer fill the matchmaking
server's connections, and accounts are better protected against password guessing.

**Settings and account fixes.** The controller list in Settings no longer repeats itself each time you change a
button or preset, and the Range preset's D-pad down shows its action. When a sync fails, the Account tab now says why
instead of always telling you to sign in again. And if your results aren't reaching the online boards (your name
belongs to an account you're signed out of), the Stats tab says so.
