# 2026-10-05

**The Ring pace setting now works in SpeedKills.** Under Adjust settings, the battle royale's Ring box (Slow, Normal,
Fast) did nothing in SpeedKills: the city's decay ran at the same speed whatever it said. Now Slow gives you a longer
match and Fast a shorter one, as it says. It turned up while the game's automatic tests were being moved over from the
old game to SpeedKills, so they now check the game people actually play.
