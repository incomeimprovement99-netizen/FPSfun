# 2026-11-03

**Scrolling the settings no longer changes them.** Scrolling the menu with the mouse over a number box you had just clicked,
such as your mouse's DPI, quietly changed its value. Now the menu scrolls and the value stays put.

**The gun onto the back.** Starting a climb, an emote, a loot or a throw, a soldier's rifle jumped from the hands onto the back
in a single frame. It now dissolves out of the hands and back in on the back, the way it already came back.
