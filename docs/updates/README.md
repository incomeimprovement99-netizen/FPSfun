# Daily updates

One file a working day, `YYYY-MM-DD.md`, written as the day's work lands: what
shipped, what it cost, what was found on the way, and what is next. They are
for reading back a week later, so they say what changed and why rather than
listing commits, which `git log` already does, and they are written for the
owner rather than for a stranger.

The roadmap (`docs/DEVELOPMENT_ROADMAP.md`) keeps a Milestone per shipped
feature and is the record of the project; these are the diary next to it.
