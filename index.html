Getting past 60 fps, step by step

A browser only draws when the screen can show a new frame, so your display's refresh rate is the ceiling. On this PC the game itself runs at 800+ fps on Competitive, so the cap is the screen and the browser, not the game.

  1. Set your monitor to its top refresh rate. Windows: Settings, System, Display, Advanced display, Choose a refresh rate. Pick the highest number (144, 165, 240 Hz). If only 60 is offered, the cable or port is the limit: use DisplayPort (or HDMI 2.0 or newer) and plug it into the graphics card, not the motherboard.
  2. Fully restart Chrome so it picks up the new rate: close every window, and if Chrome stays in the system tray, right-click it there and choose Exit. Come back here and this box shows the new number.
  3. Turn off Energy Saver. Chrome: Settings, Performance, Energy Saver off. It can cap pages at 30 fps.
  4. Check hardware acceleration is on. Chrome: Settings, System, Use graphics acceleration when available on, then Relaunch. The address chrome://gpu should say WebGL is hardware accelerated.
  5. Laptops and PCs with two GPUs: Windows Settings, System, Display, Graphics, add Chrome, Options, High performance, so it runs on the graphics card.
  6. Optional: go past the refresh rate. Like turning V-Sync off in a game: more frames and lower latency, with some screen tearing.
    1. Right-click the desktop, New, Shortcut.
    2. Paste this as the location (it is a separate Chrome profile, so your normal Chrome and its settings are untouched):
      "C:\Program Files\Google\Chrome\Application\chrome.exe" --user-data-dir="C:\ChromeUncapped" --disable-frame-rate-limit --disable-gpu-vsync http://localhost:5173
    3. Name it Chrome Uncapped and open it. It opens this page.
    4. Check the FPS counter, top right in game: it should now go past your refresh rate.
  7. Still stuck? In the GPU driver, set V-Sync to off or application controlled. AMD Software: Gaming, Graphics, Wait for Vertical Refresh. NVIDIA Control Panel: Manage 3D settings, Vertical sync.
